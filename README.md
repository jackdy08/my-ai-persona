# 个人 AI 档案仓库（persona）

> 本文件用途：告诉任何 AI Agent / 人类访客，这个仓库是什么、该怎么读、按什么顺序读。
> 维护方式：纯 Markdown、轻量、人可读、AI 也可直接拉取原文理解。

## 这是什么

这是我的**跨 AI、跨设备通用个人档案仓库**。
无论我在哪个 AI 产品（ChatGPT / Claude / Gemini / 豆包 / Kimi / 通义 / 本地大模型等）里对话，
我都会让 AI 先读这个仓库，再开始回答。这样所有 AI 对"我是谁、我喜欢什么、我怎么做事、我已经知道什么"
的理解都是一致的，不需要每次重新解释一遍。

## 仓库里有什么

| 文件 | 作用 |
|---|---|
| `README.md` | 本文件，仓库总说明 |
| `00-index.md` | 总索引，AI 应先读这个文件，再按清单依次读其余文件 |
| `01-about-me.md` | 我的基础背景、身份、家庭、长期目标、硬件环境 |
| `02-preference.md` | 沟通偏好、输出风格、明确禁止的事项 |
| `03-work-rules.md` | 工作原则、做事习惯、交付与验证规范 |
| `04-format-template.md` | 常用输出模板（周报、总结、方案、笔记） |
| `05-knowledge.md` | 长期积累的领域知识、家庭环境配置、已确认事实 |
| `06-changelog.md` | 修改记录 |

## AI 读取顺序（重要）

任何 AI 在和我对话前，应按以下顺序读取：

1. `README.md`（本文件）——理解仓库用途；
2. `00-index.md`——拿到完整文件清单与读取顺序；
3. 按 `00-index.md` 列出的顺序，依次读取 `01` 到 `05`；
4. `06-changelog.md` 只在需要判断"哪些内容是新更新的"时再看。

读取后：
- 把 `01~03` 的内容作为**长期行为约束**，贯穿整段对话；
- 把 `04` 作为**输出格式参考**，当我要求写周报/方案/总结时套用；
- 把 `05` 作为**已知事实库**，不要重复问我已经写清楚的事；
- 不要把档案全文复述给我，直接按设定工作即可。

## 安全约定

- **本仓库可能是公开仓库**，因此：
  - 不写真实密码、API Key、Token、家庭详细住址、身份证、手机号；
  - 涉及密钥的位置只写"见私人备忘 / 已在本地配置"，不留明文；
  - 硬件型号、内网 IP 这类信息可以写，因为它们不是凭证。
- 如果我后续把仓库设为 Private，再按需补充敏感环境信息。

## 更新方式

- 每次修改一个文件，顺手在 `06-changelog.md` 追加一行：日期 + 改了什么；
- 大改某个主题时，先在对应文件顶部"最后更新"日期上改一下；
- 不要重命名已有文件，AI 是按文件名硬编码去读的。
